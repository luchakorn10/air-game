# AIR Drone Puzzle Mission

Web App สำหรับกิจกรรมโดรน 5 เกม · โรงเรียนสร้างเสริมทักษะเทคโนโลยีเอไอแอนด์โรโบเทค

## แนวคิด: ห้องแข่ง → กลุ่ม → คะแนน
- **Admin สร้าง "ห้องแข่ง" ทุกครั้งที่ไปสอน** (1 โรงเรียน / 1 ห้องเรียน) พร้อมกำหนดจำนวนกลุ่ม
- ระบบสร้างกลุ่มให้ล่วงหน้า แต่ละกลุ่มมี **บัตรกลุ่ม** (QR + PIN 4 หลัก) → ครูพิมพ์แจกกลุ่มละใบ
- นักเรียนสแกนบัตร → เข้ากลุ่มทันที → **ตั้งชื่อกลุ่มได้ครั้งเดียว** (ครูแก้/ปลดล็อก/ล็อกทั้งห้องได้) — นักเรียนสร้างกลุ่มเองไม่ได้ จึงไม่มีกลุ่มมั่ว/ซ้ำ
- คะแนนแยกตามเกม + รวมทั้งห้อง · นักเรียนดูคะแนนกลุ่มตัวเองและตารางของห้องได้ที่ `/room`

| เกม | การคิดคะแนน |
|---|---|
| 1 ผีถ้วยแก้ว, 2 แม่ไก่ออกไข่ | ครูกด +/− ให้คะแนนแต่ละกลุ่มในหน้า Admin |
| 3 ยอดนักสืบจิ๋ว โค-โดรน | สแกน QR → ตอบ 4 ตัวเลือก ตอบได้ครั้งเดียวต่อคำใบ้ (อัตโนมัติ) |
| 4 สิงห์ป่าสั่งลุย | เลือกสัตว์ป่าสงวน/บุคคลต้องสงสัย ถูก +1 ผิด −1 ส่งครั้งเดียว (อัตโนมัติ) · ระบบสร้างการ์ดสัตว์ให้พิมพ์ |
| 5 เจ้าเวหาล่าพลาซ่า | สแกน QR 4 จุด → เขียน Block Code · ครูกดตรวจภารกิจ |
| ทุกเกม | ครูให้โบนัส/หักคะแนนเพิ่มได้ |

| หน้า | URL | ใครใช้ |
|---|---|---|
| หน้าแรก / กติกา | `/`, `/game?id=detective` | ทุกคน |
| เข้ากลุ่ม | `/join` (บัตรกลุ่มพาไปเอง) | นักเรียน |
| กลุ่มของฉัน + คะแนน | `/room` | นักเรียน |
| เล่นเกม / สแกน QR | `/play?g=...`, `/q?c=...` | นักเรียน |
| จอคะแนน | `/board?r=รหัสห้อง` (`&g=เกม`) | โปรเจคเตอร์ |
| Admin | `/admin` | ครู / ทีมงาน |
| พิมพ์บัตรกลุ่ม / QR / การ์ด | `/admin/cards?room=…`, `/admin/print?game=…` | ครู |

**ใช้อะไรทำ:** HTML/CSS/JS ล้วน ไม่ต้อง build + Cloudflare Pages Functions (API) + D1 (ฐานข้อมูล) + KV (เก็บรูป)
ภาพการ์ด/คำใบ้ใช้ [Twemoji](https://github.com/jdecked/twemoji) (กราฟิก CC-BY 4.0) · กล้องสแกน QR ในหน้าเว็บใช้ [jsQR](https://github.com/cozmo/jsQR) (Apache-2.0) · รายชื่อสัตว์ป่าสงวนอ้างอิง พ.ร.บ.สงวนและคุ้มครองสัตว์ป่า พ.ศ. 2562

## 1) รันบน local (Windows)

ต้องมี [Node.js](https://nodejs.org) เวอร์ชัน 18 ขึ้นไป แล้วเปิด Terminal ในโฟลเดอร์ `air-puzzle`

```bash
npm install          # ติดตั้ง wrangler (ทำครั้งแรกครั้งเดียว)
npm run db:init      # สร้างฐานข้อมูลจำลอง + ใส่ข้อมูลตั้งต้น (รันซ้ำ = รีเซ็ตข้อมูลทั้งหมด)
npm run dev          # เปิดเว็บที่ http://localhost:8788
```

- รหัสผ่าน admin สำหรับ local อยู่ในไฟล์ `.dev.vars` (ค่าเริ่มต้นคือ `air1234`)
- **ทดสอบสแกน QR ด้วยมือถือ:** ให้มือถือกับคอมต่อ Wi-Fi วงเดียวกัน แล้วเปิดหน้า admin ผ่าน IP ของคอม เช่น `http://192.168.1.20:8788/admin` เพราะ QR จะสร้างลิงก์ตามที่อยู่ที่ใช้เปิดหน้า admin (ถ้าเปิดผ่าน `localhost` มือถือจะเปิดลิงก์ใน QR ไม่ได้) ดู IP ได้ด้วยคำสั่ง `ipconfig` และถ้า Windows Firewall ถาม ให้กด Allow

## 2) ขึ้น prod → air-game.pages.dev

```bash
npx wrangler login
npx wrangler d1 create air-puzzle-db            # คัดลอก database_id ไปใส่ใน wrangler.toml
npx wrangler kv namespace create IMAGES         # คัดลอก id ไปใส่ใน wrangler.toml
```

จากนั้นทำต่อดังนี้

1. Push โปรเจกต์ขึ้น GitHub (ไฟล์ `.dev.vars` และ `node_modules` ถูก ignore ไว้แล้ว)
2. ไปที่ Cloudflare Dashboard → Workers & Pages → Create → Pages → Connect to Git → เลือก repo
   - Project name: `air-game` (จะได้ URL `air-game.pages.dev`)
   - Build command: เว้นว่าง
   - Build output directory: `public`
3. ไปที่ Settings → Variables and Secrets แล้วเพิ่ม `ADMIN_PASSWORD` แบบ Secret (ใช้รหัสที่เดายาก)
4. ไปที่ Deployments แล้วกด Retry deployment เพื่อให้ binding และ secret มีผล

หลังจากนี้ทุกครั้งที่ `git push` เว็บจะอัปเดตอัตโนมัติ

> ฐานข้อมูลบน Cloudflare จะสร้างตาราง + ข้อมูลตั้งต้นให้เองอัตโนมัติในครั้งแรกที่มีคนเปิดเว็บ (ดู `lib/bootstrap.js`) · ถ้าแก้ `schema.sql`/`seed.sql` ให้รัน `npm run build:db` ก่อน push

## หลักการสำคัญ
- QR เก็บแค่รหัส แก้คำใบ้ได้ตลอดโดยไม่ต้องพิมพ์ QR ใหม่ · ถ้ารหัสหลุดกด "สร้างรหัสใหม่"
- เกมโค-โดรน: โจทย์จะเปิดให้เห็นเฉพาะตอนกรรมการกดเริ่มแล้ว (กันแอบสแกนดูก่อน)
- คะแนนจะเปิดให้ผู้เรียนเห็นเมื่อจบรอบ (Admin เห็นตลอด) · ตั้งค่า "บอกถูก/ผิดทันที" ได้ในเกมโค-โดรน
- สิงห์ป่า: ถูก (สัตว์สงวน/บุคคลต้องสงสัยที่อยู่ในสนาม) +1, ผิด (ไม่ใช่สัตว์สงวน หรือไม่อยู่ในสนาม) −1
- ชื่อรายการแสดงบน QR ที่พิมพ์ ห้ามใส่เฉลยในชื่อ
